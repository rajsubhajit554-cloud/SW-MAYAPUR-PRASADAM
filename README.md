# Mayapur Prasadam Website

Welcome to the **Mayapur Prasadam** website project repository.

## Project Structure
- `index.html` - The main homepage HTML.
- `styles.css` - Custom styling/animations.
- `script.js` - Dynamic interactions, animations, and transitions.
- `assets/` - Static assets, images, icons, and logos.
- `update_git.bat` - Automation script to update and push your changes to GitHub.

---

## How to Update the GitHub Repository
We have created a helper batch file called `update_git.bat` in the root folder to make it easy to upload/push changes to GitHub.

### Steps:
1. Double-click `update_git.bat` (or run it via command prompt: `.\update_git.bat`).
2. The script will show you the current modified files.
3. It will ask if you want to push changes. Press `Enter` (or type `Y` and press `Enter`).
4. Type a short description of the changes you made (e.g., `updated logo` or `fixed styling`) and press `Enter`.
5. The script will automatically add all files, commit them, and push them to GitHub.
